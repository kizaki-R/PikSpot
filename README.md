# PikSpot

標記你的探索紀錄。

PikSpot 是一個 Android 小工具，可接收遊戲開啟 Google 地圖時送出的座標連結，擷取座標並複製到剪貼簿。

## 功能

- 擷取 Google Maps 座標連結
- 自動複製座標到剪貼簿
- 透明攔截座標連結，複製後立即返回原 App
- 顯示最近擷取座標
- 保留歷史紀錄，最多 99 筆
- 支援釘選、分享、刪除歷史紀錄
- 一般網址自動轉交 Chrome

## 使用方式

安裝後請依 App 內設定指引：

1. 將 PikSpot 設定為預設瀏覽器。
2. 將 Google 地圖連結選項改為在瀏覽器中開啟。
3. 開啟「啟用座標擷取」。

## 注意

- 這是非官方工具。
- PikSpot 不修改遊戲、不讀取遊戲資料，只處理 Android 傳入的地圖連結。
- 目前版本：V1.1。
