# PikSpot

標記你的探索紀錄。

PikSpot 是一個 Android 小工具，可接收遊戲開啟 Google 地圖時送出的座標連結，擷取座標並複製到剪貼簿。

## 下載

最新版本請至 GitHub Releases 下載：

[PikSpot V1.2](https://github.com/kizaki-R/PikSpot/releases/tag/v1.2)

## 功能

- 擷取 Google Maps 座標連結
- 自動複製座標到剪貼簿
- 透明攔截座標連結，複製後立即返回原 App
- 顯示最近擷取座標
- 座標剪貼簿最多保留 99 筆
- 支援備註、釘選、分享、刪除座標紀錄
- 支援批量複製文本、批量釘選、批量取消釘選、批量刪除
- 批量選取會顯示選取順序，文本與 GPX 依選取順序輸出
- 批量全選會依舊到新排序，方便輸出路線
- 支援批量匯出 GPX 路線檔
- 一般網址自動轉交 Chrome

## 使用方式

1. 安裝 PikSpot APK。
2. 將 PikSpot 設定為預設瀏覽器。
3. 將 Google 地圖連結設定為由瀏覽器開啟。
4. 開啟 PikSpot 內的「啟用座標擷取」。
5. 在遊戲內選擇以地圖開啟座標連結，PikSpot 會自動擷取座標並複製，不會離開遊戲畫面。

## V1.2 更新

- 「歷史紀錄」升級為「座標剪貼簿」。
- 新增座標備註管理。
- 新增批量管理，可多選複製文本、釘選、取消釘選或刪除。
- 新增全選功能，全選順序由舊到新。
- 批量選取改為圓形序號，清楚顯示輸出順序。
- 新增 GPX 路線檔匯出，依選取順序產生路線點。
- 底層座標紀錄升級為 JSON 儲存，並保留舊紀錄自動轉換。

## V1.1 更新

- 正式版發布，不再標示 Beta。
- 新增透明攔截流程：從遊戲內選擇以地圖開啟時，PikSpot 會擷取座標、複製到剪貼簿，並立即返回原 App。
- 一般網址仍會自動轉交 Chrome。

## 注意

- 這是非官方工具。
- PikSpot 不修改遊戲、不讀取遊戲資料，只處理 Android 傳入的地圖連結。
- 目前版本：V1.2。
