# PikSpot

標記你的探索紀錄。

PikSpot 是一個針對 Pikmin Bloom 推出的輔助工具。本工具不讀取遊戲資料、不修改遊戲內部代碼、不更動任何遊戲數據；核心用途是協助皮友更有效率取得座標連結，並可透過座標剪貼簿規劃 GPX 路線等功能。

## 功能

- 擷取 Google Maps 座標連結
- 自動複製座標到剪貼簿
- 攔截座標連結，不須跳轉其他 App
- 顯示最近擷取座標
- 座標剪貼簿最多保留 99 筆
- 支援備註、釘選、分享、刪除座標紀錄
- 支援批量複製文本、批量釘選、批量取消釘選、批量刪除
- 批量選取會顯示選取順序，文本與 GPX 依選取順序輸出
- 批量全選會依舊到新排序，方便輸出路線
- 支援批量匯出 GPX 路線檔
- 一般網址自動轉交 Chrome

## 使用方式

1. 安裝 PikSpot APK。
2. 將 PikSpot 設定為預設瀏覽器。
3. 將 Google 地圖連結設定為由瀏覽器開啟。
4. 開啟 PikSpot 內的「啟用座標擷取」。
5. 在遊戲內選擇以地圖開啟座標連結，PikSpot 會攔截座標並複製，不會跳轉至Google Map。

## 座標剪貼簿

擷取過的座標會自動保存到「座標剪貼簿」，最多保留 99 筆。

- 短按座標紀錄文字區：複製該筆座標。
- 備註圖示：替座標加入自訂備註，例如花點、菇點、集合點。
- 星標圖示：釘選或取消釘選該筆座標。
- 分享圖示：分享該筆座標；若有備註，會一併帶出。
- 刪除圖示：刪除該筆座標紀錄。
- 一鍵清空：清空座標剪貼簿。

## 批量管理與輸出

在「座標剪貼簿」中點選「批量管理」後，可以一次處理多筆座標。

- 點選座標列可加入/取消選取。
- 已選座標會顯示序號，序號代表輸出順序。
- 手動選取時，文本與 GPX 會依照點選順序輸出。
- 點選「全選」時，會依舊到新排序，適合輸出路線。
- 「複製文本」可將多筆座標複製成一筆一列。
- 複製文本時可選擇是否包含備註。
- 包含備註時格式為：`23.123456,123.689547; 備註內容`
- 「匯出 GPX」會將選取座標輸出成 GPX 路線檔。
- 批量管理也支援批量釘選、取消釘選與刪除。
